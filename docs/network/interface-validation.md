# Интерфейс и мастер подготовки сервера

Версия для проверки: 2.2.0-transports.4 (45). Это промежуточная тестовая сборка.

## Основной сценарий

В меню приложения кнопка «Подключения и мосты» открывает список подключений. «Добавить подключение» принимает готовую OpenFlux-ссылку, данные qWDTT или строки мостов Tor. Локальные данные распознаются автоматически, без обращения в сеть. HTTPS-подписка загружается только по явному действию и через уже защищённый маршрут. При необходимости мастер предлагает сначала настроить Tor; продолжение ждёт завершения редактора и готовности Tor. Нет автоматического перехода на прямое соединение.

Из ссылки извлекаются только действительно содержащиеся в ней параметры. qWDTT заполняет сервер и параметры профиля; несколько профилей требуют выбора. OpenFlux заполняет комнаты, ключ и контекст шифрования существующего выхода. IP VPS отсутствует в таком формате, поэтому приложение не пытается его придумать. После импорта показана сводка, подключение требует нажатия кнопки.

Основные поля отделены от дополнительных параметров. Ошибки отмечаются у полей; скрытая секция с ошибкой открывается. Запросы можно отменить, повторное нажатие во время выполнения не запускает дубликат. Выход из изменённого редактора требует подтверждения. Замена комнат подтверждается отдельно. Роль, выбранная вручную область и этап мастера сохраняются. Реальные сообщения, контакты, геолокация и экран физического устройства не использовались в автоматических проверках.

## Две среды проверки

Старые JVM-тесты включают контракты Android 9 и рассчитаны на Robolectric без манифеста. Реальные Compose-кнопки проверяются отдельно с ресурсами и Android 15:

```sh
./gradlew :app:assembleRelease :app:assembleDebug :wear:assembleDebug testDebugUnitTest lintDebug clientRewriteContractTest
./gradlew -PnetworkUiTests=true :app:testDebugUnitTest --tests '*NetworkWorkspaceButtonsTest' --tests '*NetworkSettingsColdStartTest' --tests '*NetworkWorkspaceVisualTest' --tests '*MessagesListFollowTest'
python3 -m unittest discover -s deploy/tests -v
```

Первый режим исключает только четыре перечисленных класса, выполняемые вторым режимом. Тесты действий используют синтетические профили; проверяют кнопки и вызываемые команды, валидацию, отмену, несохранённые изменения и продолжение импорта. Это не подтверждает живые соединения VK/Cups или передачу медиасообщений со стоковым клиентом.

## Комплект подготовки VPS

Администратору доступна отдельная страница с сохранением ZIP через системный выбор файла. ZIP содержит статические серверные бинарные файлы Debian x86_64, соответствующие исходники, лицензии и мастер `deploy/wizard.py`. SHA-256 проверяется при экспорте и перед развёртыванием. У пользователя нет необходимости устанавливать компиляторы для готового ZIP.

Мастер проверяет SSH-отпечаток, доступ, Debian/архитектуру, свободное место и доступность TUN, затем показывает план. SSH-пароль вводится скрыто и передаётся через временный локальный сокет без записи пароля на диск. Доступен режим `--check` без изменений. Установщики учитывают нестандартный SSH-порт. Извлечённый из APK комплект проверен на согласованном тестовом VPS: размещение ядер, установка локальной административной службы и проверка её готовности.

**Это подготовка сервера, а не законченный автодеплой VK/Cups.** Передача через эти ядра не запускается: интеграция допуска устройств с рабочими каналами ещё не завершена. Локальная служба доступа сама по себе не защищает выходные транспорты. Полное парольное хранилище приложения, две редакции и аппаратная привязка доступа также остаются отдельной незавершённой работой.

Обзор Astra был один на более ранней ревизии; новый интерфейс и мастер этим обзором не покрыты. Повторный обзор не выполнялся.

## Результаты этого комплекта

- Общая сборка release/debug, Wear, контрактные проверки: успешно.
- JVM приложения: 942 теста, 0 падений/ошибок, 3 пропущено. Wear: 245, без падений/ошибок.
- Отдельный UI-прогон: 16 тестов, без падений/ошибок. Включает путь от вставки WebTunnel до команды подключения через настоящий ViewModel с синтетическим backend.
- Мастер подготовки VPS: 7 unit tests, без падений; извлечённый ZIP проверен на согласованном тестовом VPS.
- Пять APK: подписи, версия45, minSdk29, отсутствие debug-флага, ZIP alignment, нативные компоненты и вложенный комплект проверены.
- Lint не чистый: приложение 303 ошибки / 409 предупреждений, Wear 37 / 52. В новых пакетах сетевого интерфейса и импорта ошибок нет; есть рекомендации UseKtx для настроек мастера. Успешная задача lint не означает чистый отчёт.
- Физическая установка в этом этапе не выполнена: ADB не обнаружил подключённых устройств. Проверки живых мостов, VK/Cups, медиасообщений со стоковым клиентом и Android/GrapheneOS остаются невыполненными.
