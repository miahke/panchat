# Отчёт проверки Bitchat Transports

Статус: тестовая сборка, не производственный выпуск. Основа — Bitchat Android v2.2.0. Android minSdk 29, targetSdk 37. Сохраняются форматы Nostr, Noise, идентичностей и приватных сообщений Bitchat.

## Выполнено локально

- Общий финальный прогон Gradle завершён успешно: assembleRelease, assembleDebug для приложения/Wear, testDebugUnitTest, lintDebug и clientRewriteContractTest.
- Release APK: arm64-v8a, armeabi-v7a, x86_64, x86 и universal. R8 включён; `debuggable=false`; все APK подписаны одним отдельным тестовым ключом. Проверены подписи, minSdk, applicationId и ZIP alignment.
- Во всех вариантах проверены Arti, obfs4/WebTunnel, VK и Cups: наличие, ELF architecture/PIE, выравнивание страниц и отсутствие путей сборочной машины. Контрольные суммы Arti совпадают с закреплёнными. JSON с результатами: package-verification.json.
- Debug APK приложения и Wear собраны. Контрактные проверки протокола выполнены.
- JVM приложение: 865 тестов, 0 ошибок/падений, 3 пропущено. Wear: 245 тестов, ошибок/падений нет.
- Go qWDTT: тесты клиентского адаптера и сервера; сервер также проверен с race detector. Локальные тесты Raw v2: успешное взаимное подтверждение, отказ для старого подтверждения на свежем challenge, повтора/отражения и кадров другого сеанса. WG/Raw GETCONF и AUTH отклоняют чужого владельца до выдачи ключа и регистрации рабочего канала.
- Cups: тесты обязательного шифрования/аутентификации, передачи DNS через туннель, повтора, подмены кадра и неправильного ключа.
- TLS: тесты проверки сертификата/имени узла, защиты передаваемых байтов и отказа от открытого публичного WebSocket. SOCKS: проверка реквизитов, передачи доменного имени и отказа при недоступном защищённом маршруте.
- Пять тестов инструмента проверки native-упаковки; проверки контрольных сумм Arti; git diff --check.
- Один обзор GPT-6 Astra на ревизии 8fc18ef. Пять замечаний исправлены и проверены локально основным агентом. Второй обзор не выполнялся; сами исправления Astra повторно не проверяла. Подробности — security-review.md.

## Lint

Lint не является чистым: отчёт приложения содержит 303 ошибки и 399 предупреждений, Wear — 37 ошибок и 52 предупреждения. Большинство — переводы, разрешения и существующие проверки исходного приложения. Для исходного Android v2.2.0 отдельно получено 305 ошибок lint. В новых пакетах маршрутов, мостов, SOCKS, VK и сетевых настроек ошибок lint не обнаружено. Задача lint настроена upstream не останавливать сборку по этим ошибкам; успешный Gradle не означает отсутствие замечаний lint.

## Ещё не проверено

- Установка и запуск на физическом Pixel 6 Pro / GrapheneOS Android 17, отдельная установка/запуск на Android 10 и native loader для каждого ABI.
- Реальные obfs4/WebTunnel, вход VK, получение хэша и передача через VK TURN/VPS; создание комнат и живая сессия Cups.
- Серверные NAT/forwarding, восстановление после смены сети/сна/перезапуска, фоновая работа и захват трафика с проверкой отсутствия обхода туннеля на устройстве.
- Фактический обмен текстом, голосом и изображениями со стоковым Bitchat на втором устройстве; Bluetooth/Wi-Fi mesh и Wear radio interop.
- Полный аудит унаследованной криптографии и всех зависимостей. Локальный обзор и тесты не доказывают отсутствие всех уязвимостей.

Для живых испытаний используются тестовые ключи, синтетические сообщения и данные. Реальная геолокация и пользовательские переписки не нужны. VPS пользователя не изменялся; учётные данные не запрашивались. Raw v2 требует приложение и сервер из одного комплекта; старый Raw отклоняется.
