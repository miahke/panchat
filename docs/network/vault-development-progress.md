# Парольное хранилище и фоновый режим — промежуточный результат

Статус: разработка. Ранее выданные APK и исходный архив транспортного комплекта не изменены и не содержат новой парольной блокировки. Новый архив разработки содержит текущие исходники, но не является готовым защищённым выпуском.

## Принятая политика

После первого ввода пароля интерфейс можно скрыть, оставив ключи и соединения в памяти для фонового приёма. Это блокировка интерфейса, а не полное закрытие криптографического хранилища. После завершения процесса/перезапуска пароль обязателен. Для повторного открытия интерфейса планируются пароль или сильная биометрия. Отдельное полное закрытие хранилища должно отзывать ключи и останавливать транспорты.

## Реализовано и проверено локально

- Argon2id/AES-GCM конверт случайного мастер-ключа; независимый вектор Go x/crypto совпадает с Kotlin/Bouncy Castle.
- Дополнительная обёртка Android Keystore; чтение не создаёт новый ключ при потере старого. Предпочтение StrongBox с проверкой фактического уровня защиты. Аппаратное поведение ещё не проверено на телефоне.
- Атомарное сохранение/смена пароля; повреждённое или пустое существующее состояние не принимается за новое хранилище. Проверено прерывание обновления и повторное открытие.
- HKDF-ключи по назначению, аутентификация контекста записей, закрытая сессия и отклонение устаревших результатов разблокировки.
- Контроллер выбранного фонового режима: скрытие UI сохраняет ключ; полный lock отзывает; ошибочная повторная аутентификация не заменяет ключ активного фонового сеанса.
- Адаптер сетевых секретов к vault, перенос старых значений после открытия, проверка всего снимка до записи, повтор сохранения после неуспешного commit. Перенос сохраняет пустые настройки мостов Tor.
- Статический список из 34 файлов-кандидатов для дальнейшей проверки хранения; это не доказательство завершённой защиты всех данных.

Полный прогон: 893 JVM-теста приложения (3 пропущены), 245 Wear, ошибок/падений нет; 28 тестов vault. Debug-сборки app/Wear и контрактные проверки успешны. Lint завершён: у приложения остаются 303 ошибки и 401 предупреждение всего; новых ошибок в vault и NetworkSecretStore нет, только рекомендации UseKtx. Ошибки исходного проекта не считаются устранёнными. Сырые журналы и идентификаторы машины не экспортируются.

## Ещё не реализовано

Парольный экран/биометрия, подключение контроллера ко всем Activity/service/receiver/provider, полная миграция идентичности/SQLite-метаданных/голоса/изображений/кэшей, личная и публичная сборки, серверная аппаратная привязка и наш автодеплоер. NetworkRuntime пока использует прежний секретный store: новый vault-адаптер нельзя включать до корректного gating и миграции всех данных. Перед публикацией разрешения на фоновую работу нужна завершённая миграция через изолированный временный cipher, а не только проверка пароля.

Нельзя считать приложение защищённым паролем по результатам тестов этих отдельных компонентов. Новый код не проходил дополнительный обзор Astra: ранее выполнен один обзор транспортного этапа, повторный не запускался. Проверки физических устройств, живых серверов, полного хранения и межклиентского обмена остаются впереди.
