# Tor + qWDTT — удаление Cups/OpenFlux

Тестовый выпуск 2.2.0-transports.9 (50). По прямому запросу пользователя Cups/OpenFlux исключён из текущего объёма проекта.

Удалены выбор и редактор Cups, импорт OpenFlux-подписок, генератор комнат, backend, настройки Cups, нативные библиотеки четырёх ABI и исходники native/openflux. Серверный ZIP больше не содержит Cups exit и исходники OpenFlux; CLI и Android передают только qWDTT и локальную службу допуска. Владелец выдаёт новые приглашения только scope 1 (VK WG/Raw).

Старые CUPS-профили удаляются при загрузке, вместе со всеми секретами их profile ID. Настройки/секреты Tor и VK, роли и выбранная область не очищаются. Если выбран удаляемый профиль, выбор снимается. Сохраняется маркер существующего хранилища, поэтому удаление последнего профиля не создаёт прямое подключение автоматически. Новое сохранение CUPS-профиля запрещено, старый маршрут не может создать backend или получить прямой HTTP-клиент. Существующие qWDTT/Tor продолжают работать прежними протоколами.

Обозначение CUPS в enum оставлено исключительно для чтения старого JSON перед миграцией. Legacy wire-значение 2 и подписанные криптографические векторы также сохранены для совместимости данных; они не включают транспорт. Создание новых приглашений Cups из Android и owner API запрещено. Ранее выпущенные APK и соответствующие исходные архивы сохраняются как история выпусков.

Проверены миграция выбранного Cups и сохранение выбора VK, очистка только удалённого профиля, отказ импорту OpenFlux, закрытая маршрутизация, серверный owner API, CLI и состав ZIP. Full JVM: 964 теста, 5 пропусков, без ошибок и падений; Wear: 245 без падений. Release и контрактные проверки собраны успешно. Go admission race suite прошёл, CLI — 9 тестов, упаковщик — 6 тестов, включая запрет удалённой native-библиотеки в APK. Arti checksums и Bash syntax проверены. UI-прогон и финальная упаковка фиксируются в сопровождающем отчёте комплекта.

Общий lint репозитория и дополнительный независимый аудит этим этапом не заявляются. Полная интеграция аппаратного допуска в qWDTT, парольное хранилище всех данных и финальная активация персонального серверного выхода остаются незавершёнными. Удаление Cups само по себе их не завершает.
