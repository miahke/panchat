# Panchan: подготовка сервера qWDTT

Cups/OpenFlux удалён из текущего выпуска. Комплект содержит только сервер qWDTT WG/Raw и локальную службу допуска устройств. Android поддерживается с API 29; серверный комплект предназначен для Debian x86_64.

```sh
python3 tools/network-native/prepare-deployer.py --rebuild
python3 deploy/wizard.py --host server.example.invalid --password
# либо конкретный ключ; passphrase спрашивается скрытым вводом
python3 deploy/wizard.py --host server.example.invalid --user operator --identity ~/.ssh/id_ed25519 --key-passphrase
```

Нужны root или заранее настроенный sudo без пароля. Перед аутентификацией сверяется SSH-отпечаток с независимым источником, например панелью VPS. Для автоматического запуска используются --known-hosts или --host-key. Пароль и passphrase не входят в argv, исходники и временные файлы. Ключ не копируется в комплект. Строгая проверка host key, выбранный способ входа и identity применяются ко всем SSH-этапам. Установщик не меняет sudoers/sshd.

Прямой вызов размещения ядра: `bash deploy/stage-core.sh operator@server.example.invalid ./qwdtt-server`. Подписанный комплект сначала проверяется локально и повторно на сервере. Обновление локальной службы допуска использует общий transactional installer с проверкой готовности и откатом. При активации ядро включает IP forwarding и свои помеченные правила NAT/forward; firewall не очищается. Если хостинг блокирует транспортные UDP-порты, разрешите их отдельно в панели провайдера.

Мастер активирует qWDTT WG/Raw с отдельным локальным HTTPS API подписок. Аппаратный допуск ещё нужно связать со всеми путями конфигурации, worker и фактической передачи. Одна локальная административная служба не защищает legacy-выход. Приглашения владельца выдаются только для VK WG/Raw (scope 1).

При неуспешной проверке готовности установщик восстанавливает предыдущий бинарник и unit. База подписок и уже созданные секреты не откатываются и не удаляются. Проверка готовности подтверждает API и слушатели; живой тест через VK TURN остаётся отдельной проверкой. Зависимости устанавливаются только из настроенных репозиториев Debian; исполняемый qWDTT поставляется в комплекте и проверяется SHA-256.
