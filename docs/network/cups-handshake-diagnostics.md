# Cups: совместимость и диагностика рукопожатия

Тестовый выпуск 2.2.0-transports.8 (49). При проверке разрешённой текущей попытки на Pixel 7 Pro вход в комнаты завершился, затем 90 секунд ожидался защищённый Session handshake и наступил timeout. Комнаты и подписка не извлекались с телефона. Эта последовательность сама по себе не устанавливает, молчит ли сервер, отличается ли ключ/контекст или несовместим протокол. Пользователь сообщил, что импортировал готовую подписку.

Изменения:

- Клиент использует ограниченный набор публичных KDF-контекстов штатного OpenFlux, включая совместимый контекст списка комнат. Первичный контекст импортированного профиля сохраняется. Для любого кандидата нужны тот же секрет и подтверждённая зашифрованная Session; classic/plaintext fallback не добавляется.
- Периодическая диагностика использует только числовые счётчики Session и фиксированные коды: канал Cups ещё не отправляет кадры; кадры отправлены, но выход не ответил; ответы не прошли криптографическую проверку; расшифрованные данные не дали совместимый handshake; параметры hello отклонены; выход ответил и согласование продолжается.
- Ни ключи, ни контексты, URL, комнаты, peer ID или сырые upstream-логи в эти события не входят. Считывание статистики не обращается к ещё не запущенным транспортам.
- Android ждёт завершения настроенного бюджета ядра плюс 3 секунды на передачу результата. Общий менеджер оставляет запас 5 секунд. Раньше оба уровня использовали одинаковый срок, и Android мог убить процесс раньше отчёта ядра.
- Общая ошибка больше не затирает уже полученную конкретную ошибку Cups. Диагностическая подсказка сохраняет причину перед timeout, но перестаёт показывать прежнюю ошибку после положительного этапа согласования.

Проверки: Go race-набор клиента и upstream transport; синтетическое согласование с правильным секретом и другим публичным salt, отказ неправильному секрету; классификация счётчиков; Android-проверки причин timeout и управления маршрутом. Живой временный Cups-выход без аккаунта прошёл полный encrypted Session → authenticated SOCKS → DNS → HTTPS с обычной проверкой TLS, также с race detector. Это отдельный тестовый выход, а не доказательство работы пользовательской подписки.

Полный JVM-набор: 975 тестов, 5 пропусков, без ошибок/падений. Release собран. Нативный клиент Cups пересобран для arm64-v8a, armeabi-v7a, x86_64 и x86. Общий деплоер и исходники серверного ядра включают тот же upstream API диагностики; изменение wire protocol сервера для этой правки не требуется. Для старого classic/stream выхода или неработающей службы могут понадобиться совместимый Session-режим и обновлённая подписка; текущая попытка этого ещё не доказывает.

Новый независимый обзор и полный lint этим исправлением не заявляются. Полная активация транспортов и аппаратный допуск общего проекта остаются отдельной незавершённой частью.
